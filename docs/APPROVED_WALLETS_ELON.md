# ATLANTIS — Elon Musk mentions — Approved Wallets

Lista humana de wallets aprobadas para la vertical "Elon Musk mentions"
(mercados tipo "Elon Musk # of tweets", "What will Elon post this week?",
"Elon Musk Net Worth on..."). Espejo de `docs/APPROVED_WALLETS.md`, pero
completamente separada — nunca se mezcla con el roster de deportes.

Fase actual: **exploración/screening**, sin conexión a `consensus-backtest`,
`active-portfolio` ni ejecución real todavía.

## Estados

- `approved`: entra al análisis.
- `paper_only`: solo observación.
- `paused`: no analizar temporalmente.
- `rejected`: conservar histórico, pero no usar para señales — usar para
  bots confirmados. Ojo: esta categoría es más propensa a bots de velocidad
  de reacción a tweets (ver README, sección de gotchas de la vertical Elon).
